## ℹ️ Про проект

Робота присвячена використанню технологій штучного інтелекту для обробки та аналізу зображень за допомогою сучасних бібліотек OpenCV, TensorFlow, Keras та Stable Diffusion. У межах роботи розглядаються методи розпізнавання об’єктів і облич, обробки відео, побудови та навчання нейронних мереж, а також генерації та модифікації зображень за допомогою моделей штучного інтелекту. Особлива увага приділяється практичному застосуванню комп’ютерного зору та глибокого навчання для автоматизації аналізу візуальних даних.

### 🎯 Мета роботи
Ознайомитись з операціями читання, відображення та збереження зображень з використанням пакетів штучного інтелекту для мови програмування Python, а також опанувати практичні навички роботи з нейромережами.

## 🛠 Стек технологій

### 👁️ OpenCV
OpenCV (Open Source Computer Vision Library) — бібліотека функцій та алгоритмів комп'ютерного зору з відкритим кодом. Вона надає засоби для розпізнавання об'єктів, обробки відеопотоків, перетворення зображень та виявлення ключових точок.

### 💎 Dlib
Dlib — інструментарій для машинного навчання, що спеціалізується на вирішенні реальних задач, таких як високоефективне розпізнавання облич та обробка графічних структур.

### 🧠 TensorFlow & Keras
TensorFlow — бібліотека від Google для побудови та тренування нейронних мереж. Keras виступає як високорівневий API, що дозволяє швидко прототипувати глибокі моделі навчання.

### 🎨 Stable Diffusion
Stable Diffusion — модель прихованої дифузії для перетворення тексту в зображення (Text-to-Image). Вона дозволяє генерувати деталізовані зображення на основі текстових запитів або модифікувати існуючі візуальні дані.

## 🔬 Опис лабораторних робіт

### 1️⃣ Лабораторна робота №1: Основи обробки зображень
Вивчення базових функцій OpenCV: фільтрація, зміна розміру, кольорові простори та морфологічні операції.

### 2️⃣ Лабораторна робота №2: Виявлення облич та об'єктів
Використання каскадів Хаара (Haar Cascades) та бібліотеки Dlib для знаходження облич та ключових точок обличчя (landmarks) на фото та відео.

## ⚙️ Встановлення та запуск

### 💻 Вимоги
- Python 3.8+
- GPU з підтримкою CUDA (рекомендовано для Stable Diffusion)

### 🚀 Налаштування середовища

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/YuHryshchenko/zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026.git
   cd zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026
   ```

2. Створіть віртуальне середовище:
   ```bash
   python -m venv venv
   source .venv/bin/activate  # для Linux/macOS
   # venv\Scripts\activate   # для Windows
   ```

3. Встановіть необхідні бібліотеки:
   ```bash
   pip install opencv-python imutils numpy tensorflow dlib diffusers transformers
   ```
   or
   ```bash
   pip install -r requirements.txt
   ```
