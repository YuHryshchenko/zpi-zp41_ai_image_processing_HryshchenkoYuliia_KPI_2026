## ℹ️ Про проект

Робота присвячена використанню технологій штучного інтелекту для обробки та аналізу зображень за допомогою сучасних бібліотек OpenCV, TensorFlow, Keras та Stable Diffusion. У межах роботи розглядаються методи розпізнавання об’єктів і облич, обробки відео, побудови та навчання нейронних мереж, а також генерації та модифікації зображень за допомогою моделей штучного інтелекту. Особлива увага приділяється практичному застосуванню комп’ютерного зору та глибокого навчання для автоматизації аналізу візуальних даних.

### 🎯 Мета роботи
Ознайомитись з операціями читання, відображення та збереження зображень з використанням пакетів штучного інтелекту для мови програмування Python, а також опанувати практичні навички роботи з нейромережами.

## 🛠 Стек технологій

### 👁️ OpenCV
OpenCV (Open Source Computer Vision Library) — бібліотека функцій та алгоритмів комп'ютерного зору з відкритим кодом. Вона надає засоби для розпізнавання об'єктів, обробки відеопотоків, перетворення зображень та виявлення ключових точок.

### 💎 Dlib
Dlib — інструментарій для машинного навчання, що спеціалізується на вирішенні реальних задач, таких як високоефективне розпізнавання облич та обробка графічних структур.

### 👤 Face Recognition
Високорівнева бібліотека для розпізнавання облич, побудована на базі Dlib, що дозволяє знаходити обличчя та їхні ключові точки, а також порівнювати їх із високою точністю.

### 🧠 TensorFlow & Keras
TensorFlow — бібліотека від Google для побудови та тренування нейронних мереж. Keras виступає як високорівневий API, що дозволяє швидко прототипувати глибокі моделі навчання.

### 🎨 Stable Diffusion
Stable Diffusion — модель прихованої дифузії для перетворення тексту в зображення (Text-to-Image). Вона дозволяє генерувати деталізовані зображення на основі текстових запитів або модифікувати існуючі візуальні дані.

### 🖼️ ImageAI
ImageAI — це потужна бібліотека Python, яка дозволяє розробникам легко інтегрувати передові можливості комп’ютерного зору у свої додатки. Вона надає прості API для розпізнавання, детекції та аналізу об'єктів, підтримуючи популярні архітектури, такі як YOLO та RetinaNet.

## 🔬 Опис лабораторних робіт

### 1️⃣ Лабораторна робота №1: Основи обробки зображень
Вивчення базових функцій OpenCV: фільтрація, зміна розміру, кольорові простори та морфологічні операції.

### 2️⃣ Лабораторна робота №2: Виявлення облич та об'єктів
Використання каскадів Хаара (Haar Cascades) та бібліотеки Dlib для знаходження облич та ключових точок обличчя (landmarks) на фото та відео.

### 3️⃣ Лабораторна робота №3: Комп'ютерний зір для детекції дорожньої розмітки
🚩 **Мета:** Розробка конвеєра для автоматичного виявлення смуг руху на зображеннях та відеопотоці.

**Основні етапи реалізації:**
*   **Попередня обробка:** Перетворення в Grayscale та застосування Gaussian Blur для усунення шумів.
*   **Детекція меж:** Використання оператора Кенні (Canny Edge Detection).
*   **Виділення ROI:** Накладання маски (шестикутного полігону) для фокусування на проїжджій частині та відсікання капота автомобіля.
*   **Перетворення Гафа:** Застосування `HoughLinesP` для знаходження сегментів ліній.
*   **Агрегація та екстраполяція:** Фільтрація ліній за нахилом (slope), групування їх у ліву та праву смуги, обчислення середнього значення та малювання суцільних ліній розмітки поверх оригіналу.

### 4️⃣ Лабораторна робота №4: Система розпізнавання облич на базі Dlib
👤 **Мета:** Створення системи ідентифікації осіб за допомогою глибокого навчання та 128-вимірних векторних представлень (embeddings).

**Технічні деталі та компоненти:**
*   **Генерація бази даних (Encoding):**
    *   Використання `dlib.get_frontal_face_detector` для локалізації облич.
    *   Визначення 68 антропометричних точок за допомогою моделі ResNet.
    *   Обчислення 128-вимірного цифрового "відбитка" обличчя.
    *   Серіалізація даних у файл `encodings.pickle`.
*   **Процес розпізнавання:**
    *   Порівняння "відбитка" невідомої особи з еталонами з бази за допомогою Евклідової відстані (`np.linalg.norm`).
    *   Система голосування для підвищення точності ідентифікації.
    *   Візуалізація результатів: малювання Bounding Box та підпис імені розпізнаної особи (або "Unknown").
*   **Використані моделі:**
    *   `shape_predictor_68_face_landmarks.dat`
    *   `dlib_face_recognition_resnet_model_v1.dat`

### 5️⃣ Лабораторна робота №5: Детекція об'єктів за допомогою ImageAI
🖼️ **Мета:** Побудова універсальної системи розпізнавання об'єктів на статичних зображеннях та у відеопотоці з використанням архітектури YOLO (You Only Look Once).

**Технічні деталі та компоненти:**
*   **Архітектура нейромережі:** Використання моделі **TinyYOLOv3**, яка забезпечує оптимальний баланс між швидкістю обробки та точністю детекції, що особливо важливо для відео.
*   **Гнучкість середовища:** Реалізована підтримка двох бекендів:
    *   **PyTorch** (сучасний стандарт, файли `.pt`) — основний режим роботи.
    *   **Keras/TensorFlow** (legacy режим, файли `.h5`) — для сумісності зі старими проектами.
*   **Функціональні можливості:**
    *   **Обробка фото:** Автоматичне знаходження об'єктів, малювання обмежувальних рамок (Bounding Boxes) та виведення назви об'єкта разом із ймовірністю.
    *   **Обробка відео:** Покадрова детекція з можливістю налаштування частоти кадрів (FPS) та відображенням прогресу обробки в реальному часі.
    *   **Налаштування точності:** Можливість фільтрації результатів за порогом ймовірності (`minimum_percentage_probability`).
*   **Використані моделі:**
    *   `tiny-yolov3.pt` (рекомендовано для ImageAI v3.0+)
    *   `yolo-tiny.h5` (для старих версій)

### 🚀 Лабораторна робота №6: Реалізація AlexNet для класифікації зображень

**Мета:** Побудова та навчання згорткової нейронної мережі (CNN) архітектури AlexNet для класифікації зображень з датасету CIFAR-10, а також візуалізація процесу навчання за допомогою TensorBoard.

**Технічні деталі та компоненти:**
*   **Датасет:** CIFAR-10, що складається з 60 000 кольорових зображень розміром 32x32 пікселів у 10 класах.
*   **Попередня обробка даних:**
    *   **Зміна розміру:** Зображення масштабуються до 227x227 пікселів, що відповідає вхідному розміру оригінальної архітектури AlexNet.
    *   **Нормалізація:** Значення пікселів приводяться до діапазону [0, 1] шляхом ділення на 255.0.
    *   **Розділення даних:** Навчальний набір розділяється на тренувальний та валідаційний (перші 500 зображень використовуються для валідації).
    *   **Пайплайн `tf.data.Dataset`:** Використовується для ефективної обробки, перемішування та пакетування даних.
*   **Архітектура AlexNet:**
    *   **Згорткові шари (Conv2D):** Використовуються фільтри розміром 11x11, 5x5 та 3x3 з функцією активації `relu`.
    *   **Пулінгові шари (MaxPooling2D):** Застосовуються для зменшення просторових розмірів та виділення найбільш значущих ознак.
    *   **Повнозв'язні шари (Dense):** Два шари з 4096 нейронами та функцією активації `relu`.
    *   **Шари відсіювання (Dropout):** Використовуються для запобігання перенавчанню з коефіцієнтом 0.5.
    *   **Вихідний шар:** Шар з 10 нейронами (за кількістю класів CIFAR-10) та функцією активації `softmax` для багатокласової класифікації.
*   **Компіляція моделі:**
    *   **Оптимізатор:** `adam` (Adaptive Moment Estimation).
    *   **Функція втрат:** `sparse_categorical_crossentropy` (для цілочисельних міток класів).
    *   **Метрики:** `accuracy` (точність).
*   **Навчання:** Модель навчається протягом 2 епох з використанням валідаційного набору даних.
*   **Візуалізація:** Інтеграція з TensorBoard для моніторингу процесу навчання (втрати, точність) та архітектури мережі.

## ⚙️ Встановлення та запуск

### 💻 Вимоги
- Python 3.8+
- GPU з підтримкою CUDA (рекомендовано для Stable Diffusion)

### 🚀 Налаштування середовища

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/YuHryshchenko/zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026.git
   cd zpi-zp41_ai_image_processing_HryshchenkoYuliia_KPI_2026
   ```

2. Створіть віртуальне середовище:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/macOS
   # venv\Scripts\activate   # для Windows
   ```

3. Встановіть необхідні бібліотеки:
   ```bash
   pip install opencv-python imutils numpy dlib face_recognition tensorflow keras keras-resnet pillow scipy h5py matplotlib imageai
   ```
   або
   ```bash
   pip install -r requirements.txt
   ```
